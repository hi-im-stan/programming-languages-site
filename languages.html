Table of Contents What are programming Languages? Programming languages are ways in which we give computers and other digital devices instructions. Without instructions – otherwise known as programs or software, your PC or your mobile phone is just a paper weight or door stop. Computers – whether in the form of desktop machines, phones, tablets, or games consoles – are multi-purpose machines. With a different program they can do a different task. This is called the stored program concept where the program in main memory can be changed to alter the behavior of the computer. This concept was developed by the code breaking pioneer Alan Turing. First generation languages The computers of the 1940s and 1950s were programming by flipping switches. One switch position indicated a “1”, the other one indicated a “0”. Soon punched paper tape supplemented switches. A hole in the tape represented a “1” and no hole a “0”. However, the basic idea is that instructions are represented by ones and zeros. The simple format of instructions is called machine code. Every modern processor, such as the Intel i9 or Arm Cortex-A725, still has its own machine code. A processor’s machine code is the only language it can execute without translation. Machine code is difficult to write programs in. It is extremely easy to make a mistake and almost impossible to find those mistakes. Fortunately, more human readable were developed. Second generation languages Second generation languages are also known as assembly languages. Rather than just using ones and zeros, assembly languages use meaningful three- or four-letter mnemonics and decimal numbers. There is a one-to-one correspondence between assembly language and machine language instructions. If a machine language instruction is 100101100000, the assembly language equivalent might be something like ADD 96. Since machine language is the only code, the processor can execute assembly language programs have to be converted into machine code. Although slightly more readable than machine languages, assembly language suffers from many of the same problems. Third generation languages. While machine code and assembly language are known as low-level languages, because they are close to the way the processor works, third-generation languages are known as high-level ones. Third-generation languages were designed to help programmers solve certain problems. They use a mixture of English words and mathematical symbols. The rules for writing high level languages are very strict. A small mistake can prevent a high-level language from running. In example of such a mistake is missing out a semi-colon on the end of the line in the language C#. Like with second generation languages, high level language programs must be translated to machine language. However, the process is much more complicated. Here are some examples of third generation languages Python Python is designed to support the rapid development of programs. It has an exceptionally large library of routines so that programmers do not need to “re-invent the wheel”. It is easy to debug Python programs by adding additional “print” statements to output the values of data items. (python.org, no date) Python was developed by Guido van Rossum in 1991. The name is a reference to the BBC TV show Monty Python’s Flying Circus (Geeks For Geeks, 2024) Go The Go programming language was created by Robert Griesemer, Rob Pike, and Ken Thompson, and released in 2009. It is written to help programmers create programs to do more than one thing at a time. It is portable, which means it will run on lots of different processors under lots of different operating systems. Go is designed to manage the computer’s main memory well, ensuring data that is no longer needed does not “clutter” up RAM. (OpenAI 2024a) Rust Like Go, key attributes are good memory management and support for “concurrent” programs where two tasks are, apparently or, done at the same time. Rust was designed to produce programs that run fast, like the older language C++. As with Python, Rust has several libraries including “Actix,” to make the creation of web applications quicker. (Wróbel, 2023). Rust became available in 2010 and was created by Graydon Hoare (Adam, 2024) Q# Q# is a language developed by Microsoft to allow the programming of quantum computers. It allows a program to create “qubits” whose state is some combination of 0 and 1, and to “entangle” these qubits so that the state of one is linked to the state of the other. The language can be used with a conventional programming language such as C# (OpenAI 2024b) Fouth Generation Languages The first three generations are what is known as “imperative” languages. In these languages the programmer must specify how to solve the problem. However, in fourth generation languages the programmer only needs to specify what the program must do. Fouth generation languages are very specialized. Specifying what the program will do still needs to be specified precisely. An ordinary English sentence will not do. SQL is an example of a fourth-generation language.
